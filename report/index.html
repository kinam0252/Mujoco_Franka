1.2 Jitter 패턴

X, Y축에서 1~2mm 단위의 좌우 진동 — Z축만 비교적 일관된 하강:

step 61: x=0.4506  ← +0.9mm (오른쪽)
step 62: x=0.4497  ← -0.9mm (왼쪽으로 되돌아감)
step 63: x=0.4506  ← +0.9mm (또 오른쪽)
step 64: x=0.4497  ← 반복...

이동 거리 자체(2mm)는 GT와 비슷하지만, 이동 방향이 매 스텝 뒤집히는 것이 문제.

2. 원인 분석: 학습량 vs 구조적 한계

2.1 학습 스텝별 비교

모델Loss방향 변화>45° 전환>90° 역방향
GT (학습데이터)—8.5°3%1%
h16_30K0.00951.6°59%12%
h32_60K0.00677.1°74%37%
h50_50K0.00571.9°72%32%
결론: Loss가 0.009→0.005로 줄어도 jitter가 오히려 악화됨. 더 긴 action horizon(h32, h50)은 per-step precision이 더 낮아짐. 학습량 부족이 아니라 GR00T diffusion action head의 구조적 한계.
  • 4-step flow matching denoising이 position-level precision (~1mm)을 보장하지 못함
  • 평균 이동거리(2mm)와 비슷한 크기의 noise → 방향이 랜덤하게 뒤집힘
  • 실제 로봇에서는 관성/low-pass filtering이 자연적으로 감쇠하지만, MuJoCo kinematic mode에서는 그대로 나타남

3. EMA Smoothing 적용

3.1 EMA(Exponential Moving Average) 개요

ema_pos = α × ema_pos_prev + (1 - α) × predicted_pos
ema_quat = α × ema_quat_prev + (1 - α) × predicted_quat  (+ re-normalize)

α가 클수록 이전 값의 영향이 크고 → 부드럽지만 반응이 느림

EMA 영향 분석

항목수치설명
EMA로 해결된 에피소드6개원본에서 FAIL → EMA에서 SUCCESS

→ EMA smoothing은 jitter를 줄이지만 전체 성공률은 비슷하며, 일부 경계 케이스에서 action 지연 문제 발생.

5. Chunk 경계 불연속

action chunking에서 chunk N의 마지막 action과 chunk N+1의 첫 action 간 불연속:

pos_xpos_ypos_z
Chunk 0, step 7 (마지막)0.4604-0.04240.1314
Chunk 1, step 0 (새 예측)0.4618-0.04500.1254
Jump+1.4mm-2.6mm-6.0mm

→ open_loop_horizon=16 (전체 chunk 사용)으로 경계 불연속 최소화 가능.
